Drawdown DCA Strategy Guide

1. Peak-to-Trough Drawdown: Identifies swing pivot highs and lows. When price drops by more than the minimum drop percentage (e.g. 8%) from the peak, a DCA entry is triggered.

2. RSI Multiplier: Adjusts allocation dynamically. If RSI ≤ Oversold (e.g. 30), allocation is doubled (2x). If RSI ≥ Overbought (e.g. 70), allocation pauses (0x).

3. Heikin Ashi Candles: Filters market noise for cleaner swing pivot identification.

4. LocalStorage & URL Sync: All settings and the active filter period are stored in browser memory and URL query params across reloads.
